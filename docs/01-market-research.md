# Kiwi Finance — 市场与竞品调研报告

> 版本 v0.1 · 2026-09 · 市场优先级：**① 海外英文市场 → ② 中国大陆 → ③ 华人/东南亚细分**

---

## 0. 一页结论

| 问题 | 结论 |
|---|---|
| 这个赛道还有机会吗 | 有，但**不在"又一个记账工具"上**。工具层已饱和且免费产品（钱迹、Apple Wallet）把底价打到 0。 |
| 机会在哪 | 海外：Mint 关停留下 360 万用户的空档，接盘者定价 $95–110/年，**$0–50 价位带几乎无人**。中国：AI 记账被咔皮验证了（半年 100 万用户、T+1 留存 70%），但咔皮**手动记账体验差、功能浅、有数据可靠性投诉**。 |
| Kiwi 的可行切口 | **"AI 输入层 + 低价位"**：把咔皮的多模态录入体验（截图/语音/一句话多笔）搬到海外，绕开 Plaid 的高成本，用 $29–49/年打 Copilot/Monarch 的价格软肋。 |
| 最大风险 | 不是技术，是**留存**。记账 App 的历史共性是"下载高、次月留存崩"。产品设计必须围绕"降低单次记账成本 + 制造回看理由"。 |
| MVP 周期 | 8–12 周（不含银行聚合），首版建议 iOS 优先。 |

## 1. 对标产品拆解：咔皮记账

**基本盘**（商汤科技出品，2024 年底上线双端）

| 指标 | 数据 |
|---|---|
| 用户量 | 上线半年破 100 万；"咔皮系列"（含咔皮相机）累计千万级 |
| DAU 增长 | 年内 +400% |
| 次日留存 T+1 | ~70%（行业顶尖水平） |
| App Store 评分 | 4.8 / 5（约 5.1 万个评分） |
| 定位 | "AI 原生财务 Agent"、"你的个人 CFO" |

**核心能力（值得抄的部分）**

1. **自动记账 = 截图识别**。用户在微信/支付宝的支付结果页或订单详情页截图，AI 自动识别金额并完成分类。这是它增长的第一驱动力——**它把"记账"这个动作从 5 步压缩到 1 步**。
2. **一句话记多笔**。"今天中午吃饭 35，打车 22，买了瓶水 3 块" → 自动拆成 3 条记录并分类。
3. **多入口极速录入**。iOS 背部轻点（Back Tap）、Android 悬浮球、语音、拍照。核心思路：**记账的入口必须在 App 之外**。
4. **预算精确到"天"**。超支后立刻重新规划剩余天数的可用额度，并基于历史消费给建议。这是它最强的"回看理由"。
5. **记录心情/待办/想法**。把记账变成"消费日记"，抬高情感黏性。

**公开可见的弱点（Kiwi 的机会）**

- 手动补记体验差，**入口藏得很深**——AI 失败时用户很挫败。
- 功能深度浅：其他记账 App 的常用功能（细粒度资产、债务、报销、多账本细分）还没补齐。
- 有用户反馈**记录被误删 / 历史账目被算错**——数据可靠性口碑有裂缝。
- 强依赖扫码支付场景，**只对"主要用微信/支付宝的人"有效**，出海无法直接复制。
- AI 识别对免费用户有**每日次数限制**，高级功能"限时免费"，商业化路径尚未跑通。

> **给 Kiwi 的启示**：咔皮证明了"AI 录入"是真需求，但它把 AI 当成了全部。Kiwi 应该是 **"AI 录入 + 可靠的账本内核"**——AI 负责快，传统记账内核负责准和全。

## 2. 优先级 ① 海外英文市场（美/加/英/澳）

### 2.1 市场结构

- 约 **38% 的美国成年人每周使用个人理财 App**（美联储消费者调查口径），历史最高。
- **Mint 于 2024 年 3 月关停**，360 万用户被迫迁移。迁移只带走了账户连接和净资产，**没带走用户真正依赖的预算和分类功能** → 大量用户至今在"将就"。
- Monarch 在 Mint 关停后**增长 20 倍**。目前格局收敛为 Monarch / YNAB / Copilot / Rocket Money / Empower 五家。

### 2.2 主要玩家

| 产品 | 定价 | 强项 | 弱点 = Kiwi 的机会 |
|---|---|---|---|
| **Monarch Money** | $99.99/年（Plus $199/年） | 家庭协作、净资产、投资追踪、仪表盘干净 | AI 分类只是基础水平；价格高 |
| **YNAB** | $109/年 | 零基预算方法论，能真正改变行为；最多 6 人共享 | 学习曲线陡；**必须手动投入时间**；最贵 |
| **Copilot Money** | $95/年 / $13 月 | **分类 AI 公认最强**；设计最好；投资/净资产一体 | 长期只有 iOS（2025-12 才加 Web）；价格高 |
| **Rocket Money** | 免费 + 付费档 | 订阅取消、账单谈判，"帮你省钱"叙事强 | 预算功能弱，本质是省钱工具不是记账工具 |
| **Empower / PocketGuard / Goodbudget** | 免费～低价 | 各有细分 | 功能或体验有明显短板 |

### 2.3 关键洞察：三个结构性空档

1. **价格空档**。Mint 之死证明"完全免费 + 广告"模式不成立，但取代者集体停在 **$95–110/年**。**$29–49/年的"够用且好用"档位是空的**——这是 Kiwi 最清晰的定位。
2. **录入方式空档**。海外产品 100% 依赖银行聚合（Plaid/MX）自动导入。这带来两个后果：
   - 现金消费、拆分账单、"这 200 刀里有 80 是给朋友垫的"这类**语义信息完全丢失**；
   - **成本高**（见 §2.4），逼着它们必须定 $95+。
   - Kiwi 的差异化：**AI 多模态录入作为一等公民**——收据拍照、支付确认截图、语音、邮件解析（Amazon/Uber 收据邮件）。银行聚合作为"可选增强"而非前提。
3. **隐私空档**。相当一部分用户不愿把银行凭证交给第三方聚合商。**"不连银行也能好用"**本身就是卖点，对应中国市场的"钱迹式"信任叙事。

### 2.4 银行聚合的成本现实（决定定价的关键）

| 方案 | 价格 | 适用阶段 |
|---|---|---|
| **Plaid** | 按调用计费，Transactions 约 **$0.30–0.60/次调用**；企业合同常有 **$1,000–10,000/月**的最低承诺 | 规模化后，且必须验证 ROI |
| **Teller** | **免费 100 个 live connections**；之后 Transactions 约 **$0.30/enrollment/月** | **MVP 与早期最优解** |
| **Quiltt**（多聚合商聚合层） | Scale 档 **$1,000/月**起 | 中后期，需要多源冗余时 |
| **MX / Finicity / Yodlee / Akoya** | 企业级 | 后期备选 |

**测算**：假设一个用户平均连 3 个账户，用 Teller ≈ **$0.90/月 = $10.8/年**。
- 若 Kiwi 定价 $39/年 → 毛利率仍有 ~65%（再扣 AI 成本约 $4–6/年、应用商店抽成 15–30%）。
- **结论：银行聚合可行，但必须放在付费墙之后，且不能是 MVP 的前置依赖。**

## 3. 优先级 ② 中国大陆市场

### 3.1 竞争格局

| 产品 | 定位 | 关键事实 |
|---|---|---|
| **钱迹** | 极简 + 免费 + 无广告 | 600 万+ 用户，App Store 4.9（2.2 万评分）；"无开屏、无广告、无理财"三无；免费云同步；加入《Android 绿色应用公约》。**它是这个市场的价格地板。** |
| **咔皮记账** | AI 原生 | 见 §1 |
| **随手记** | 专业精细 | 功能最全，上手门槛高，深度功能要会员 |
| **鲨鱼记账** | 高效快捷 | 语音记账准确率约 95%；界面干净；变现走 CPS 优惠券 + 课程 + 激励视频广告 |
| **一木记账** | 自动记账 | 支付宝/微信/云闪付支付时自动记账 + 截图导入 |
| **叨叨记账 / 挖财 / 圈子账本** | 互动 / 深度分析 / 共享账本 | 各有细分人群 |

### 3.2 技术现实：中国的"自动记账"怎么实现

这是中国市场最大的技术护城河，也是**无法平移到海外**的部分：

1. **Android 无障碍服务（Accessibility Service）**——识别微信/支付宝支付页的节点信息，抓取生成账单（钱迹的做法）。
2. **截图 / 长截图 OCR** ——识别支付结果页或账单列表长图（咔皮、一木的做法）。
3. **鸿蒙闪控球** + 系统级 AI 能力，点一下自动识别当前屏幕。
4. **iOS 端只能靠**：快捷指令（Shortcuts）、背部轻点、通知内容、共享扩展（Share Extension）。**iOS 无系统级自动记账通道**，这就是为什么咔皮把截图识别做成核心。

### 3.3 商业化现实（劝退项）

- 主流变现是**广告 + 会员 + 电商 CPS + 卖课**，而非纯订阅。
- 行业公认痛点：**"空有痛点，难有未来"**——记账枯燥、习惯难养成、打开率低、流失率高。
- 用户付费意愿远低于海外（年费普遍 ¥50–100 量级）。
- 合规成本：App 备案、《个人信息保护法》、金融相关内容审核、应用商店上架（安卓需上架华为/小米/OPPO/vivo/应用宝多个渠道）。

> **结论：中国市场适合作为第二阶段。** 它验证产品快、获客便宜，但天花板低、合规重、且要正面对上一个免费且口碑极好的钱迹。

## 4. 优先级 ③ 华人 / 东南亚细分市场

**目标人群**：留学生、外派、跨境电商从业者、新移民、双城生活者。

**未被满足的需求**（现有产品几乎都不做）：
- **多币种真实记账**：不是简单换算，而是记录"当时汇率 + 实际到账"，支持 CNY/USD/SGD/MYR/THB 混合账本。
- **跨账户体系**：同时有中国的微信/支付宝/银行卡 + 海外的银行卡/PayPal/Wise。
- **家庭跨境转账追踪**：给国内父母打钱、收家里的钱。
- **中英双语 UI + 双语 AI 识别**（同一条语音里中英混杂）。

**判断**：盘子小、但获客成本极低（社群传播强、竞争几乎为零）、付费意愿介于中美之间。
**建议**：不作为独立产品线，而是**海外版的一个"多币种模块"**——用最小增量吃这个人群，作为早期口碑放大器。

## 5. 综合判断：Kiwi Finance 的定位假设

> **Kiwi = 给不想连银行、也不想每月花 $9 的人做的 AI 记账本。**
> 拍一张收据 / 截一张图 / 说一句话，账就记好了；月底告诉你钱去哪了。

**四条定位支柱**

| 支柱 | 具体主张 | 对标谁 |
|---|---|---|
| **① AI 录入是一等公民** | 收据/截图/语音/邮件 → 结构化交易，准确率是核心 KPI | 抄咔皮，海外无人做 |
| **② 不连银行也完全可用** | 银行聚合是可选增强，不是前提 | 打 Copilot/Monarch 的隐私与成本软肋 |
| **③ 价格带 $29–49/年** | 免费档够日常用，付费档解锁 AI 额度 + 聚合 + 家庭共享 | 打价格空档 |
| **④ 数据可靠 + 可导出** | 本地优先、永不误删、一键导出 CSV/JSON | 打咔皮的口碑裂缝，抄钱迹的信任叙事 |

**明确不做的事**（避免陷阱）
- ❌ 不做投资组合追踪（Monarch/Copilot 的深水区，投入产出比低）
- ❌ 不做贷款/理财产品导流（毁信任，且触发金融合规）
- ❌ 不做社交feed（记账是私密行为）
- ❌ MVP 不做 Android（海外优先 iOS，用户付费率高 2–3 倍）

## 6. 核心风险清单

| 风险 | 级别 | 应对 |
|---|---|---|
| **留存崩塌**（行业通病：次月留存 <20%） | 🔴 高 | 把"每日预算余额"做成核心回看理由 + 小组件 + 每周复盘推送 |
| AI 识别准确率不达标（用户对错误零容忍） | 🔴 高 | 建立 500+ 条真实收据/截图的评测集，准确率 <92% 不上线；永远保留 1 秒可改的手动修正 |
| Plaid/Teller 成本失控 | 🟡 中 | 聚合放在付费墙后；按连接数计费而非用户数；先用 Teller |
| 苹果审核（金融类 App 审核严） | 🟡 中 | 不碰"投资建议"措辞；隐私标签如实填写 |
| 大厂降维（Apple Wallet 内建预算功能） | 🟡 中 | 靠"跨账户 + AI 语义"做差异，Apple 只能覆盖 Apple Card/Pay |
| 中国市场合规（备案、PIPL） | 🟢 低（阶段二才触发） | 阶段二立项时单独评估 |
