# Kiwi Finance

AI 驱动的个人记账 App。

> **一句话定位**：给不想连银行、也不想每年花 $100 的人做的 AI 记账本 —— 拍一张收据、截一张图、说一句话，账就记好了。

## 当前状态

调研与规划阶段（Phase 0 前）。尚无代码。

## 市场优先级

1. **海外英文市场**（美/加/英/澳）— iOS 优先
2. **中国大陆** — 第二阶段
3. **华人 / 东南亚细分** — 作为海外版的多币种模块
