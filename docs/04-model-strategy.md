## 0. 一页结论

| 问题 | 结论 |
|---|---|
| 两个市场能用同一套模型吗 | **不能。** 中国市场用境外模型没有合规路径 —— 这是硬约束，不是偏好问题 |
| 海外选什么 | **Gemini 为主**：3.7 Flash 做提取（OCR 榜单第一梯队且最便宜），2.5 Flash-Lite 做分类，3.1 Pro 做复核与叙述。OpenAI 作为容灾与 Planner 备选 |
| 中国选什么 | **已备案的国产模型 API，不做二次开发** → 只需 AI 应用登记（轻），避开 3–6 个月的大模型备案 |

| 最重要的工程动作 | **模型抽象层 + 统一评测集**。换模型 = 改配置；进中国 = 换一组配置 |
| 最大的隐藏风险 | Gemini 3.7 Flash 的 $0.75/$3.75 是 **2026-12-31 到期的促销价**，之后翻倍。预算必须按正价做 |

## 1. 硬约束：中国市场为什么必须换一套

这一节先讲清楚，因为它决定了后面所有选择。

**① 境外模型没有合规路径**
《生成式人工智能服务管理暂行办法》适用于**向中华人民共和国境内公众提供生成式 AI 服务**的主体 —— 境外 AIGC 产品用于向境内公众提供服务时同样适用。叠加数据出境的限制，直接调用 OpenAI / Gemini 服务中国用户不是"贵一点"的问题，是走不通。

**② 但有一条轻路径**

| 你做的事 | 需要办什么 | 周期 |
|---|---|---|
| 自研 / 训练 / 对大模型二次开发 | **大模型备案** | 3–6 个月 |
| **纯调用已备案的第三方模型 API，无二次开发** | **AI 应用登记** | 显著更轻 |

> **策略结论**：中国版**只调用已备案的国产模型 API，不做微调、不做二次开发**。把所有产品逻辑留在提示词、Report Spec 和确定性引擎里 —— 这正好是我们 [`03` 架构](./03-ai-native-architecture.md)天然的样子。合规成本因此从"3–6 个月备案"降到"应用登记"。

**③ 内容安全红线（2026 现行）**
敏感问题拒答率 ≥ 95%，非拒答测试合格率 ≥ 96%。记账类应用天然低风险，但**用户备注字段是自由文本**，必须过内容安全接口。

## 2. 四个工作负载

模型选型必须按负载分开谈，因为它们的要求完全不同。

| 负载 | 频次 | 首要要求 | 失败的代价 |
|---|---|---|---|
| **A · 交易分类** | 最高（规则拦截后仍有 70 次/月/人） | 极致便宜、快 | 低 —— 用户一键改，且改完即成规则 |
| **B · 收据/截图提取** | 高（60 次/月/人） | **多模态 OCR 准确率** | **最高 —— 这是产品生死线** |
| **C · Planner（NL → Report Spec）** | 低 | **结构化输出的 schema 合法率** | 中 —— 有校验器兜底，但失败即重试烧钱 |
| **D · Narrator（叙述/月报）** | 低 | 中文/英文写作质量 | 中 —— 读起来蠢会掉品牌分 |

| 模型 | 综合 | OCR | 数据抽取 | 定价 |
|---|---|---|---|---|
| **Gemini 3.7 Flash** | **85%** | 87% | **94.8%（31 个模型中第 2）** | $0.75/$3.75 |

**读法**：3.7 Flash 在**结构化数据抽取**（就是我们要干的事）上最强且便宜；3.1 Pro 在**纯文字识别**上更准。这直接决定了下面的级联设计。

### 3.3 三套组合

#### 方案 A · Gemini 单供应商 ⭐ 推荐

| 负载 | 模型 | 理由 |
|---|---|---|
| A 分类 | Gemini 2.5 Flash-Lite | $0.10/$0.40，任务简单，隐式缓存自动 90% off |
| **B 提取** | **Gemini 3.7 Flash** | 数据抽取 94.8% 且是同档最便宜的多模态 |
| B 复核 | Gemini 3.1 Pro（仅 ~10% 低置信样本） | OCR 93%，专治糊图和手写 |
| C Planner | Gemini 3.7 Flash + `responseSchema` | 后面有 JSON Schema 校验器兜底 |
| D Narrator | Gemini 3.1 Pro（月报走 Batch 五折） | 写作质量够，成本可控 |

✅ 一个 SDK、一套配额、隐式缓存零配置、OCR 第一梯队、总成本最低
⚠️ 单供应商风险；结构化输出的严格性弱于 OpenAI 的 strict 模式

#### 方案 B · OpenAI 单供应商

| 负载 | 模型 |
|---|---|
| A 分类 | GPT-5-nano（$0.05/$0.40，全场最便宜） |
| B 提取 | GPT-5.6 Terra 视觉 |
| C Planner | GPT-5.6 Terra + **strict Structured Outputs** |
| D Narrator | GPT-5.6 Terra，月报走 Batch |

✅ 结构化输出保证最强（Report Spec 场景的真实优势）；工具链最成熟
⚠️ 多模态提取比 Gemini 3.7 Flash 贵约 **2.7 倍**，且公开视觉评测不占优 —— 而提取恰好是我们成本和质量的大头

#### 方案 C · 混合（各取所长）

分类 `GPT-5-nano` · 提取 `Gemini 3.7 Flash + 3.1 Pro 复核` · Planner `GPT-5.6 Terra` · Narrator `GPT-5.6 Terra`

✅ 每个环节都用最合适的；两家互为容灾
⚠️ 两套 SDK / 两份账单 / 两套限流与重试逻辑。**对 1 人团队，这个复杂度不值得**

> **我的建议：MVP 走方案 A，但把 OpenAI 适配器一起写好**（约 1 天工作量），作为提取环节的容灾与 A/B 对照。等有了真实评测数据再决定是否切到方案 C。

## 5. 跨市场架构：模型抽象层

这是唯一能同时服务两个市场且不重写代码的做法，**必须在 Phase 0 就定下来**。

```
                    ┌─────────────────────────┐
产品代码 ──调用──▶  │   ModelRouter            │
（只知道任务）       │   task  × region → model │
                    └────────────┬─────────────┘
                                 ↓
              ┌──────────┬───────────┬──────────┬──────────┐
              │ OpenAI   │ Gemini    │ 百炼      │ DeepSeek │  适配器
              └──────────┴───────────┴──────────┴──────────┘
```

**四条设计规则**

1. **产品代码只认任务，不认模型**：调用方说的是 `extract(receipt)`，不是 `gemini.generateContent(...)`
2. **每个任务是一份 capability contract**：输入格式、输出 JSON Schema、超时、单次成本上限、降级策略 —— 换模型不得改契约
3. **供应商适配器只做协议翻译**：把统一契约翻译成各家 SDK 调用，负责重试、限流、错误归一化
4. **配置驱动路由**：`{task, region, tier} → {provider, model, params}` 存在配置里，**换模型 = 改配置，进中国 = 换一组配置**

**附带好处**：A/B 测试、灰度切换、供应商故障自动降级、按用户档位分配模型（免费用户用更便宜的档）—— 全都是这套抽象的自然结果。

## 6. 三个必须做的工程动作

### ① 评测集先行，不测不选

500+ 条真实收据与支付截图（**中英各半**，含糊图、手写、长截图、多币种小票）。任何模型选型都跑同一套，输出同一张准确率/成本/延迟表。

**不测就选 = 赌博。** 公开榜单只能用来缩小候选范围，不能用来做决定 —— 榜单里没有你的用户的小票。

### ② 把两段式提取作为对照组

| 方案 | 做法 |
|---|---|
| 直出 | 图 → 通用多模态模型 → 结构化 JSON |
| **两段式** | 图 → **专用 OCR**（文字+版面+表格） → 便宜文本模型 → 结构化 JSON |

中国市场已有明确证据支持两段式（0.9B 专用模型打赢通用 VLM，成本 1/10）。海外也应对照测 —— 如果结论一致，海外提取成本还能再降一个量级。

### ③ 按正价做预算

- Gemini 3.7 Flash `$0.75/$3.75` → **2026-12-31 后 `$1.50/$7.50`**
- GPT-5.6 Sol 的 8-21 降价是 **3 个月促销**

促销价当红利，不当基准。模型定价在 2026 年是**高频变动项**（OpenAI 在 7 月和 8 月两次降价），所以模型抽象层不只是工程整洁，它是**议价能力** —— 能随时切换的人才有议价权。

## 8. 待决策

1. **海外主供应商** —— 方案 A（Gemini 单家，推荐）还是方案 C（混合，Planner 用 OpenAI strict schema）
2. **是否投入两段式提取的对照实验** —— 约 3 天工作量，潜在收益是提取成本降一个量级
